Professional experience

Senior Associate — Automation Engineer · Accenture

Client: BMW Group — Customs Hub · August 2024 – Present · Bengaluru, India
  • Built an AI-augmented test automation framework for BMW's Customs Hub, a vehicle customs clearance application for UK and Republic of Ireland imports, using Java, Playwright, Cucumber BDD and TestNG (Page Object Model), with LLM-assisted test generation and DeepEval-based quality checks on AI output.
  • Evaluated LLM and RAG output quality with DeepEval, scoring answer relevancy, faithfulness, contextual precision and hallucination against curated golden datasets, and wired these metrics into the CI pipeline as pass/fail quality gates.
  • Piloted LLM-based test generation, converting business requirements and customs process documentation into Cucumber feature files and step definitions using structured prompt templates (role, context, output schema).
  • Used Playwright MCP to let an LLM agent explore the application, inspect the live DOM/accessibility tree and draft locators and end-to-end flows, reviewed and refactored into the Page Object Model.
  • Built a RAG-style pipeline indexing user stories, acceptance criteria and process documentation so the LLM generates test cases grounded in actual requirements, reducing hallucinated or out-of-scope scenarios.
  • Used LLMs to generate edge-case scenarios and synthetic test data for customs workflows (valid, boundary and invalid inputs).
  • Applied LLM-as-judge evaluation with defined rubrics (G-Eval style) to score free-text responses that exact-match assertions cannot verify, calibrated against manual review.
  • Tested chatbot / conversational AI behaviour: intent handling, response accuracy, consistency across rephrased inputs, multi-turn context and refusal of out-of-scope requests.
  • Ran adversarial and guardrail tests on LLM features, including prompt injection, jailbreak attempts and sensitive-data leakage checks, logging findings as defects.
  • Applied AI-assisted self-healing locators and LLM-based analysis of Azure DevOps failure logs to reduce flaky failures and classify issues (script, environment, product defect) faster.
  • Established human-in-the-loop review for all AI-generated tests before merging.
  • Validated end-to-end customs workflows across upstream and downstream systems (status transitions, message flows, data consistency) using REST Assured, Postman and SQL.
  • Automated cross-browser regression suites (Chrome, Firefox, Edge, Safari) in Azure DevOps CI/CD pipelines; prepared weekly Extent Reports dashboards and collaborated in Agile ceremonies with BMW stakeholders.
